## One project. Five connected days.

Build **Tamweel Lite**, a synthetic financing-risk project that develops from a baseline model into a reproducible, explainable and calibrated decision system.

You will compare models, control leakage, respect time and customer groups, handle class imbalance, choose a threshold under simulated decision cost and review-capacity constraints, explain predictions, assess calibration, evaluate ensembles and deliver a complete GitHub project.

</td>
<td width="50%" valign="top" dir="rtl">

## مشروع واحد. خمسة أيام مترابطة.

ابنِ مشروع **Tamweel Lite** ببيانات تمويل اصطناعية، يبدأ بخط أساس ثم يتطور إلى نظام قرار قابل لإعادة الإنتاج والتفسير والمعايرة.

ستقارن النماذج، وتمنع التسرب، وتحترم الزمن ومجموعات العملاء، وتعالج عدم توازن الفئات، وتختار عتبة ضمن تكلفة قرار تعليمية وسعة مراجعة، ثم تفسر التنبؤات وتقيم المعايرة والتجميع وتسلم مشروع GitHub متكاملًا.
