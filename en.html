LEARNING EXAMPLE

What is “simulated loss”?

Errors do not carry equal weight: missing a default counts as 10 loss units; a false alarm counts as 1.

Loss = 10 × FN + FP

3 missed defaults + 20 false alarms = 50 loss units.

This simulates the impact of mistakes. It is not a fee or a direct grade deduction.

A SHARED VOCABULARY

Terms you will use

Baseline

A simple reference used to compare later models.

Boosting

Sequentially adding learners to improve an objective.

Leakage

Using information unavailable at decision time.

OOF

A prediction from a model not trained on that row.

Threshold

A cutoff that turns risk probability into a decision flag.

False negative

A default case that the model did not flag.

False positive

A non-default case that the model flagged.

Calibration

Comparing predicted probabilities with observed frequencies.

SHAP

Feature contributions in a defined output space, not proof of causality.

Ensemble

Combining model predictions; the benefit needs evidence.

Model Card

Documentation of purpose, data, method, results and limits.

Reproducibility

Rebuilding results from specified data, settings and code version.

Common questions

Do I need to pay for any tools?

No. Every required activity has a free route. If a service limit is reached, save your work and try later or follow the free alternative announced by the instructor.

Can I run the labs now?

Notebooks 00 through 05 are available now. Open all five daily labs from their learning-journey cards and save your evidence in the same project.

Must a particular model win?

No. Make a fair comparison and justify your choice using evidence. Keeping a single model is valid when an ensemble adds no convincing benefit.

Do I need paid PowerPoint?

No. Use a free presentation tool and submit a PDF. What matters is five clear slides backed by your own project evidence.

My Colab files disappeared. What now?

The runtime is temporary. Recover your saved notebook, rerun the released version and export the outputs. Save your progress before the session ends.
