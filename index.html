CAPSTONE SCENARIO

Tamweel Lite

A synthetic financing-risk simulation. Estimate a default event within 90 days, then define a simulated review policy under explicit error-loss and capacity constraints.

Educational simulation only. It must not be used for real lending or employment decisions.

سيناريو المشروع

Tamweel Lite | تمويل

محاكاة اصطناعية لمخاطر التمويل. قدّر حدث تعثر خلال 90 يومًا، ثم حدد سياسة مراجعة محاكاة في ظل خسارة أخطاء وسعة معلنتين.

محاكاة تعليمية فقط، ولا تستخدم لاتخاذ قرارات تمويل أو توظيف فعلية.

BEFORE YOU START

Recommended foundations

  • Basic Python and pandas
  • Binary classification and probabilities
  • Train, validation and test roles
  • Confusion matrix, precision and recall

No GPU, API key, paid subscription, local installation or Drive mount is required.
